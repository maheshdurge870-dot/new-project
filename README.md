# CampusEvent - College Program Management System

## Features
- Role-based access (Admin, Faculty, Student, Volunteer)
- Program management (CRUD)
- Student registration & ticketing
- Attendance tracking
- Certificate generation & verification
- Volunteer management
- Analytics & Reports
- AI Assistant (Optional)

## Prerequisites
- Node.js 18+
- Python 3.10+

## Backend Setup
1. `cd backend`
2. `python -m venv venv`
3. Activate virtual environment (`source venv/bin/activate` or `venv\Scripts\activate`)
4. `pip install -r requirements.txt`
5. `uvicorn main:app --reload`

## Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`
